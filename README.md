# Proyecto Aarón — Demo

Landing estática con Vite. No requiere backend para la vista previa.

## Iniciar

```bash
npm install
npm run dev
```

Abrí la dirección local que aparece en la terminal (habitualmente http://localhost:5173).

## Publicar

```bash
npm run build
```

En Vercel: Framework Vite, Build Command `npm run build`, Output Directory `dist`.

## Importante

Esta es una demostración visual. El formulario no guarda ni envía datos; el calendario no crea reservas; los videos y resultados son espacios reservados. Sustituir por contenido auténtico y conectar el sistema de reservas antes de lanzar.

## Personalización

Los estilos, textos y scripts están en `index.html`. Color coral aproximado: `#f05d6b`.
